# Meme Is Mine design direction

Editorial meme studio: the joke is the artifact. Cream paper, near-black typography and deliberate vermilion. Real meme images do the expressive work; tool surfaces are calm and legible.

Home persuades through a working caption example, image collection, real editor capabilities, video collection, local studio, native FAQ and a concise maker credit. Avoid repeated process sections, invented testimonials, ornamental badges, generic feature-card grids, decorative infinite motion, shader backgrounds and artificial loading delays.

Use the existing React, Lucide and Motion stack. CSS for simple feedback; Motion only where gesture behavior needs it. Native details for disclosures. No additional component framework required for these simple interactions.

Tokens: paper #f5f0e7, surface #fbf8f2, ink #151515, secondary #625c54, accent #c83221, decorative red #f0442e. Space Grotesk display with tracking >= -0.04em; DM Sans body; Georgia only for selective editorial emphasis. Self-host fonts. Spacing 4/8/12/16/24/32/48/64/96/128. Controls 44px touch targets. Text inputs 16px on mobile. Visible focus; reduced-motion support. Landing display <=96px, app display <=72px.

Signature: changing a caption in the first viewport changes the actual meme preview immediately. No imitation editing controls. The complete editor remains the primary path. Desktop is a split composition; mobile puts the promise and action before the compact demo.
