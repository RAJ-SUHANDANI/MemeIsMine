# Meme Is Mine — actual website launch video

This is a **real browser recording** of https://memeismine.vercel.app/ edited into a short launch film. All visuals inside the film are frames recorded by Playwright/Chromium from the production website. There are **no recreated interfaces, generated site screenshots, mock editors, stock images, or fabricated features**.

## What appears
1. The website's branded introduction.
2. The live homepage and the working caption input changing an actual meme preview.
3. The real homepage image carousel.
4. The public image-template collection at /explore.
5. The public video-template collection at /video-templates.
6. The live homepage outro.

The source script is deterministic and uses only public signed-out flows; it does not impersonate a logged-in account or claim that an export was completed. Rendering uses FFmpeg and a track bundled with the MIT-licensed /brag skill. The music "Happy Beats / Business Moves" is by ende.app under CC BY 4.0; attribution is required when publishing.
